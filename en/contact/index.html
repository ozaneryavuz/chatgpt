For a useful response

What should the message contain?

  • The topic and relevant ALO186 page address
  • A short description of the error or suggestion
  • An official source and review date, where available
  • For a technical issue: device, operating system, browser and screen width
  • A screenshot only after masking personal fields

ALO186 does not provide an emergency field response or run an official consumer application. Use a qualified electrician for an installation fault, 186 for the public grid and 112 for immediate danger.

Do not send

  • Identity or passport images
  • Electricity subscription or contract number
  • Card or bank information
  • Exact address or live location
  • Images showing interference with sealed equipment
Never request emergency intervention by email. Move to a safe place and call 112 for electric shock, fire, smoke, arcing or a fallen wire.

Contact address: info@alo186.com. Sending occurs through the user's own email application.
